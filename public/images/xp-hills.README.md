# Desktop wallpaper

`xp-hills.webp` is an original image made with the built-in image generation tool, then resized to 1600 × 900 and encoded as WebP (about 160 KB). It is used as a static desktop background and cropped banner; it is not an animation or CSS gradient.

Prompt:

> Create a single landscape wallpaper asset for a retro early-2000s desktop web UI. Photographic gently rolling vivid green grass hill across the lower half, bright blue summer sky with scattered soft white clouds above. Nostalgic Windows XP desktop atmosphere, clean simple composition, hill crest slightly left of center. Wide 16:9 landscape. Wallpaper ONLY: no text, no windows, no icons, no taskbar, no UI, no logos, no watermark. Natural photographic tones, no artificial gradient overlay.
